# Healthcare-Analytics
Project

## Project Overview

An end-to-end healthcare analytics project using SQL, Python, MySQL, and Power BI to analyze healthcare data and generate actionable insights.

## Project Goals

- Analyze patient demographics and healthcare trends
- Identify diagnosis and treatment patterns
- Analyze healthcare utilization metrics
- Build SQL-based analytical reports
- Create interactive Power BI dashboards
